# Support

| Need                    | Where to go                                                                                  |
|-------------------------|----------------------------------------------------------------------------------------------|
| Bug reports             | [GitHub Issues](https://github.com/Pharaonic/php-slugify/issues/new/choose) (bug report template) |
| Feature requests        | [GitHub Issues](https://github.com/Pharaonic/php-slugify/issues/new/choose) (feature request template) |
| Security vulnerabilities | See [SECURITY.md](SECURITY.md). Never use public issues.                                  |
| Usage questions         | The [documentation](https://pharaonic.io/packages/php/slugify) and the [Pharaonic Discord community](https://discord.gg/XQG9RhvEvf) |

Before opening an issue, please check the [README](README.md), the [migration guide](MIGRATION.md), and existing issues.

This is an open-source project maintained on a best-effort basis. There are no guaranteed response times.
